# CyberTech Portfolio

A high-performance, responsive personal portfolio built with React, Vite, and Tailwind CSS. Tailored with a Cyber/Terminal aesthetic and automated GitHub REST API data injection.

## 🚀 Features
- **Dynamic Data:** Fetches profile info, top repositories, and a GitHub contribution calendar via REST API.
- **Resilience:** Built-in rate limiting handling with cache/fallback UI.
- **Cyber Aesthetic:** Dark mode defaults, neon accents, monospaced typography, and CSS-based animations.
- **Performance:** Optimized static export architecture targeting a 90+ Lighthouse Score.
